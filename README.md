# finngolf-media

Öffentliche Ablage für **freigegebene** Instagram-Bilder von [@finngolf.de](https://www.instagram.com/finngolf.de/).

Instagram holt Bilder für Beiträge nur von einer öffentlichen Adresse ab. Deshalb liegen hier ausschließlich Bilder,
die ohnehin veröffentlicht werden. Keine Entwürfe, keine persönlichen Daten.

Struktur: `posts/<post-id>/<nr>.jpg` (JPEG, 1080 × 1350).
